Adarsh AI Clone — Run & Operation Guide

1. Prerequisites & Environment Setup:
   Ensure Python 3.10+ is installed, then install all dependencies:
   python -m pip install -r requirements.txt

2. Launch Ollama Engine:
   Ensure Ollama is running locally:
   ollama serve

3. Download / Verify Model:
   Ensure the llama3.2:3b model is pulled:
   ollama pull llama3.2:3b

4. Start the Application:
   python app.py

5. Access the Web Interface:
   Open your browser to:
   http://127.0.0.1:7860
   (Note: If port 7860 is already in use by another session, Gradio will automatically bind to http://127.0.0.1:7861 or the exact port printed in the terminal).

Key Features & Operations:
- Avatar Display: Displays your custom high-resolution avatars (new_avatar_idle.png and new_avatar_talking.png), automatically switching between idle and speaking states in real time.
- Zero-Latency Voice Engine: Speaks instantly using native Windows SAPI5 (Microsoft David Desktop) with ultra-low latency (<35ms start time), guaranteeing reliable multi-turn playback across all consecutive messages without hanging or delay.
- Instant Cancellation: Press the red "⏹ Stop" button at any time to instantly cut off speech playback and reset the avatar to idle.
- Multi-Turn Memory: Automatically restores recent chat history into the UI on startup and persists new conversations to chat_history.json.
- Voice & Microphone Input: Hold or click the mic button to speak; transcription is fed directly to the model.
- HTML Presentation: Open index.html in any browser to view the 13-slide academic presentation for the PBL-2 project evaluation.
